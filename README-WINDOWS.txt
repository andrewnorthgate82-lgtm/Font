راهنمای ویندوز — نسخه اصلاح‌شده

مشکل قبلی این بود که بعد از وارد کردن اطلاعات، پوشه خروجی خودکار باز نمی‌شد یا کاربر از داخل خود ZIP اجرا می‌کرد.
در این نسخه، فایل اجرایی منویی اضافه شده و بعد از ساخت فایل، پوشه خروجی را خودکار باز می‌کند.

مراحل دقیق:

1) فایل ZIP را دانلود کن.

2) خیلی مهم: روی ZIP راست‌کلیک کن و Extract All را بزن.
   از داخل خود ZIP دوبار کلیک نکن.

3) وارد پوشه‌ای شو که Extract شده است.

4) روی این فایل دوبار کلیک کن:
   KARKARD-WINDOWS-MENU.bat

5) صفحه سیاه باز می‌شود و یک منو نشان می‌دهد:
   1 - Generate ONE month
   2 - Generate ALL months of a year
   3 - Open output folder
   4 - Exit

6) اگر می‌خواهی یک ماه بسازی، عدد 1 را بزن.
   سپس:
   - شماره ماه را وارد کن، مثلاً 5 برای مرداد
   - سال را وارد کن، مثلاً 1405
   - نام را وارد کن یا Enter بزن تا پیش‌فرض بماند

7) اگر می‌خواهی کل سال را بسازی، عدد 2 را بزن.

8) بعد از ساخته شدن فایل، پوشه خروجی خودکار باز می‌شود.
   مسیر خروجی:
   karkard\output

9) اگر خروجی را ندیدی:
   دوباره KARKARD-WINDOWS-MENU.bat را اجرا کن و گزینه 3 را بزن.

10) اگر خطای Python گرفتی:
   Python را نصب کن:
   https://www.python.org/downloads/
   هنگام نصب تیک Add python.exe to PATH را بزن.

فایل‌های مهم داخل ZIP:
- KARKARD-WINDOWS-MENU.bat      ← بهترین گزینه اجرا
- START-HERE-WINDOWS.bat        ← همان منوی اصلی را باز می‌کند
- GENERATE-ALL-1405-WINDOWS.bat ← ساخت سریع کل سال 1405
- README-WINDOWS.txt            ← همین راهنما
