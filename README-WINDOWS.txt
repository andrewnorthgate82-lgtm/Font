راهنمای اجرای ویندوز

نکته خیلی مهم:
فایل ZIP را باز نکن و مستقیم از داخل ZIP اجرا نکن.
حتماً اول Extract All بزن.

مراحل:

1) فایل ZIP را دانلود کن.

2) روی ZIP راست‌کلیک کن و گزینه Extract All را بزن.

3) وارد پوشه Extract شده شو.

4) برای ساخت یک ماه:
   روی فایل START-HERE-WINDOWS.bat دوبار کلیک کن.
   سپس ماه و سال را وارد کن.

5) برای ساخت کل سال 1405:
   روی فایل GENERATE-ALL-1405-WINDOWS.bat دوبار کلیک کن.

6) خروجی اکسل‌ها اینجا ساخته می‌شود:
   karkard\output

7) اگر خطای Python گرفتی:
   Python را از این آدرس نصب کن:
   https://www.python.org/downloads/

   هنگام نصب حتماً تیک این گزینه را بزن:
   Add python.exe to PATH

8) بعد از نصب Python دوباره فایل bat را اجرا کن.

نام فایل‌های مهم داخل ZIP:
- START-HERE-WINDOWS.bat
- GENERATE-ALL-1405-WINDOWS.bat
- README-WINDOWS.txt
- karkard\karkard.py
