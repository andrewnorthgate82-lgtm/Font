# نمونهٔ آزمایشی تولید تصویر محلی برای Android

این اپ جدا از POC متنی ساخته می‌شود تا یک مسیر متفاوت از MNN Chat روی Redmi Note 13 Pro+ آزمایش شود. از MediaPipe Image Generator `0.10.26.1` و یک تبدیل ثالث Stable Diffusion 1.5 استفاده می‌کند. **این API از سوی Google منسوخ‌شده و دیگر فعالانه نگهداری نمی‌شود؛ این فقط آزمون فنی است و معماری نهایی v1 نیست.**

## Build 0.1.1 — رفع خطای شروع

نسخهٔ اول APK با خطای `No virtual method build()Lcom/google/protobuf/Any;` هنگام آغاز موتور متوقف می‌شد. نسخهٔ 0.1.1 وابستگی ناسازگار protobuf-lite را حذف می‌کند و از protobuf runtime سازگار با API تولیدشدهٔ MediaPipe استفاده می‌کند. هنگام نصب به‌صورت به‌روزرسانی، فایل مدل خصوصی برنامه باید حفظ شود؛ اگر Android از تعارض امضا گفت، برنامه را حذف نکن و ابتدا خبر بده.

## مدل و دریافت

- مدل: `cuesetac/sd15-mediapipe`، فایل `sd15-mediapipe.zip`، حدود 2.07 GB.
- نسخهٔ مدل در URL به commit مشخص pin شده و SHA-256 آن در اپ بررسی می‌شود.
- آرشیو پس از دریافت در پوشهٔ خصوصی اپ از حالت فشرده خارج و سپس حذف می‌شود. مدل استخراج‌شده داخل اپ باقی می‌ماند.
- برای دانلود و استخراج موقتاً حدود 5 GB فضای خالی لازم است؛ دانلود از داخل اپ فقط روی شبکهٔ Wi‑Fi غیر-metered مجاز است.
- اتصال اینترنت فقط برای دریافت اولیهٔ مدل است. پس از آماده‌شدن مدل، تولید باید بدون شبکه انجام شود؛ حالت پرواز برای آزمون همین موضوع پیشنهاد می‌شود.

مدل Stable Diffusion 1.5 ذیل مجوز [CreativeML OpenRAIL-M](https://huggingface.co/spaces/CompVis/stable-diffusion-license) است و محدودیت‌های استفادهٔ پیوست مجوز همچنان اعمال می‌شوند. پیش از قراردادن مدل در نسخهٔ تجاری، شرایط مجوز و منبع تبدیل را دوباره بررسی کنید.

## نتیجهٔ میدانی اولیه روی Redmi

در آزمون کاربر روی Redmi Note 13 Pro+ با اپ MNN Chat و مدل MNN Stable Diffusion 1.5 OpenCL، سه خروجی تصویری بررسی شد: زمان‌های ثبت‌شده 1,376.66 s، 258.26 s و 416.73 s بودند. هر سه خروجی به نویز رنگی و بخش خاکستری خراب شدند و برای استفاده قابل‌قبول نیستند. در اسکرین‌شات اجرای سوم نماد حالت پرواز دیده می‌شود؛ اگر حالت پرواز پیش از فشردن Generate روشن بوده، این اجرای تکمیل‌شده تأیید می‌کند که مسیر بدون شبکه کار می‌کند، هرچند کیفیت خروجی مردود است.

نسخهٔ دقیق MNN Chat، تنظیمات backend/steps/resolution، دما و تغییر باتری ثبت نشده‌اند؛ علت ریشه‌ای را نمی‌توان قطعی دانست. این نتیجه فقط مسیر فعلی MNN Chat + مدل OpenCL را روی این گوشی رد می‌کند و به‌تنهایی ثابت نمی‌کند که تولید تصویر کاملاً روی دستگاه ناممکن است. برای همین POC جداگانهٔ MediaPipe ساخته می‌شود؛ همان MediaPipe نیز آزمایشی و منسوخ‌شده است.

## روش آزمون روی گوشی

1. APK آزمایشی را از Release نصب کن؛ مدل داخل APK نیست.
2. فضای خالی را بررسی کن و از Wi‑Fi برای دانلود 2.07 GB استفاده کن.
3. صبر کن تا اپ SHA-256 را بررسی و فایل را استخراج کند؛ این مرحله ممکن است زمان‌بر باشد، پس اپ را نبند.
4. پس از نمایش «مدل آماده است»، حالت پرواز را روشن کن.
5. یک prompt انگلیسی وارد کن و با 12 گام پیش‌فرض، یک تصویر 512×512 تولید کن. 12 گام فقط برای آزمون اولیه است؛ نتیجهٔ کیفیت نهایی را نشان نمی‌دهد.
6. زمان تولید، PSS فرایند، وضعیت حرارتی Android و درصد باتری قبل/بعد در اپ ثبت می‌شوند. برای خروجی می‌توان تصویر را در گالری ذخیره و گزارش را کپی کرد.

آزمون build یا شبیه‌ساز، سازگاری واقعی، کیفیت، سرعت، RAM، گرما و پایداری روی Redmi را اثبات نمی‌کند. فقط نتیجهٔ خود گوشی معیار تصمیم است.
