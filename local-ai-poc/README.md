## مرحلهٔ استودیو 0.2.0 — اتصال واقعی موتور متن

APK متنی اکنون با شناسهٔ جدید `com.font.localstudio` و نام «استودیوی محتوا — آزمایشی» ساخته می‌شود. این یک نصب جداگانه است، نه update اپ قبلی. هر دو APK با کلید پایدار Secrets امضا می‌شوند. برنامه‌های قبلی را حذف یا Clear data نکنید. مدل‌های فضای خصوصی اپ قبلی خودکار منتقل نمی‌شوند؛ برای اجرای این نسخه دانلود انتخابی E2B (حدود 2.6 GB) یا E4B (حدود 3.7 GB) در همین اپ لازم است. APK شامل وزن مدل نیست.

مسیر واقعی افزوده‌شده: بارگذاری مدل → موضوع/مخاطب/نوع محتوا → تولید سه پیشنهاد JSON با همان LiteRT-LM → انتخاب پیشنهاد → ویرایش عنوان، متن و کپشن → ذخیره و بازکردن آخرین پروژه. تاریخچهٔ revision در فایل atomic نگه داشته می‌شود؛ هنوز رابط مرور تاریخچه و فهرست چند پروژه وجود ندارد. ذخیره دستی است؛ خروج بدون زدن ذخیره ممکن است ویرایش‌ها را از دست بدهد. داده‌ها فقط در حافظهٔ داخلی اپ‌اند و با uninstall پاک می‌شوند.

سه نوع اولیه: سواد رسانه‌ای، پوستر، اینفوگرافیک. در این نسخه فقط متن و ساختار پیشنهادی تولید می‌شود، نه طرح تصویری نهایی. ویرایشگر گرافیکی، موتور تصویر در اپ مشترک، مدیریت چند فضای کاری و انتشار هنوز متصل نیستند. تأیید انتشار در این رابط وجود ندارد و خروجی صرفاً پیش‌نویس است.

خروجی مدل دادهٔ غیرقابل‌اعتماد است: تعداد/عنوان‌های متفاوت و فیلدهای ضروری بررسی می‌شوند. JSON ناقص/نامعتبر پروژهٔ قبلی را بازنویسی نمی‌کند و متن خام برای بررسی باقی می‌ماند. تفاوت معنایی ایده‌ها و صحت ادعاها نیاز به بازبینی انسانی دارد. تولید سه پیشنهاد سقف 1536 توکن دارد و روی CPU ممکن است چند دقیقه طول بکشد. دکمهٔ توقف موجود است. این مسیر هنوز روی گوشی واقعی تأیید نشده است.

تست‌های هسته و parser پیش از امضا و انتشار در CI اجرا می‌شوند؛ تست واحد، کیفیت تولید واقعی مدل یا ذخیره/بازیابی روی گوشی را اثبات نمی‌کند.

# نمونهٔ آزمایشی هوش مصنوعی محلی برای Android

این پروژه یک **پروتوتایپ سنجش روی گوشی** است، نه اپ انتشار شبکه‌های اجتماعی. برای Redmi Note 13 Pro+ با RAM فیزیکی ۱۲ GB (طبق اعلام کاربر) طراحی شده و از AI ابری یا API انتشار استفاده نمی‌کند.

## در این نمونه چه هست؟

- اپ بومی Kotlin برای Android، با LiteRT-LM `0.18.0` و اجرای پایه روی CPU با ۴ رشته.
- دریافت انتخابی Gemma 4 E2B یا E4B در قالب `.litertlm`؛ فایل مدل داخل APK قرار نمی‌گیرد.
- پنج درخواست آزمایشی فارسی: کپشن اینستاگرام، پست تلگرام، پیام ایتا، متن روبیکا و حفظ دقیق نیم‌فاصله.
- اندازه‌گیری زمان بارگذاری، TTFT، تعداد و سرعت توکن‌های prefill/decode، حافظهٔ فرایند (PSS)، وضعیت حرارتی Android و درصد باتری قبل/بعد.
- کپی نتایج و متن خروجی‌ها به شکل CSV برای مقایسهٔ E2B و E4B.

## مدل‌ها و فضا

| مدل | فایل مورد انتظار | حجم تقریبی |
| --- | --- | ---: |
| Gemma 4 E2B | `gemma-4-E2B-it.litertlm` | 2.59 GB |
| Gemma 4 E4B | `gemma-4-E4B-it.litertlm` | 3.66 GB |

فایل‌ها از مخزن عمومی [LiteRT Community در Hugging Face](https://huggingface.co/litert-community) دریافت می‌شوند. خود مدل پس از دریافت روی گوشی اجرا می‌شود؛ اتصال اینترنت برای **دریافت اولیهٔ فایل‌ها** لازم است، نه برای تولید متن. پیشنهاد می‌شود دانلود با Wi‑Fi انجام شود. اپ مدل‌ها را در پوشهٔ خصوصی خودش نگه می‌دارد و برای نصب به مجوز دسترسی عمومی به فایل‌ها نیاز ندارد.

مدل‌ها هم‌زمان در حافظه بارگذاری نمی‌شوند. برای مقایسه، یک مدل را بارگذاری و آزمون کن، آن را آزاد کن و سپس مدل دیگر را انتخاب کن. هر دو فایل ممکن است در فضای ذخیره‌سازی باقی بمانند؛ از دکمهٔ حذف برای آزادکردن فضا استفاده کن.

## استفاده بدون دانش برنامه‌نویسی

قرار نیست سورس را ویرایش کنی یا دستورهای ساخت را اجرا کنی. پس از هر build موفق، APKها در [صفحهٔ Releases مخزن](https://github.com/andrewnorthgate82-lgtm/Font/releases) منتشر می‌شوند: POC متنی و یک اپ آزمایشی تصویر که جداگانه نصب می‌شود. APK تصویر مدل را درون خود ندارد؛ مدل حدود ۲٫۱ GB پس از نصب و با Wi‑Fi دانلود می‌شود.

برای نصب: APK را روی گوشی دانلود و باز کن؛ اگر HyperOS اجازهٔ نصب از این منبع را خواست، گزینهٔ اجازه را برای مرورگر/مدیریت فایل فعال کن، به فایل برگرد و «نصب» را بزن. نصب و اجرای واقعی این نسخه روی Redmi Note 13 Pro+ هنوز تأیید نشده است.

## ساخت برای توسعه‌دهنده

برای ساخت دستی، پیش‌نیازها عبارت‌اند از:

- Android Studio و JDK 17
- Android SDK Platform 36 و Build Tools سازگار
- گوشی واقعی Android 12 یا جدیدتر برای بنچمارک معتبر؛ شبیه‌ساز معیار عملکرد گوشی نیست

از Android Studio پوشهٔ `local-ai-poc` را باز کن، Gradle Sync را انجام بده و اپ را روی گوشی نصب کن. یا از ترمینال همان پوشه:

```bash
./gradlew assembleDebug
./gradlew installDebug
```

برای بارگذاری APK ساخته‌شده:

```text
app/build/outputs/apk/debug/app-debug.apk
```

اولین build به اینترنت برای دریافت Gradle و وابستگی LiteRT-LM نیاز دارد. این وابستگی‌های ساخت با دانلود وزن‌های مدل فرق دارند.

## روش آزمون پیشنهادی

1. در اپ، E2B را انتخاب و دانلود کن؛ فضای فایل مدل حدود 2.6 GB است.
2. مدل را بارگذاری کن و یک اجرای اولیه را فقط برای گرم‌شدن runtime انجام بده.
3. اجرای دقیق را در حالت پرواز تکرار کن. اگر پاسخ تولید شد، تأیید می‌شود که inference مدل پس از دانلود آفلاین است.
4. پنج مورد آزمایشی را اجرا کن. برای هر متن، طبیعی‌بودن فارسی، رعایت brief، تناسب با پلتفرم و حفظ نیم‌فاصله را **دستی** ارزیابی کن؛ فقط آزمون نیم‌فاصله یک بررسی خودکار exact-match دارد.
5. گزارش CSV را کپی کن. برای مقایسهٔ منصفانه، روشنایی صفحه و شرایط محیطی را ثابت نگه دار و همان promptها را چند بار اجرا کن.
6. مدل را آزاد کن؛ سپس همین روند را با E4B انجام بده. E4B روی سخت‌افزار دیگر ممکن است حافظهٔ بیشتری مصرف کند یا کندتر باشد؛ عملکرد Redmi فقط با اجرای واقعی روی همان گوشی مشخص می‌شود.

در POC متنی، backend فقط CPU است تا نقطهٔ شروع قابل‌تکرار داشته باشیم. GPU/NPU در این آزمون متنی دخیل نیستند. یک اپ جداگانه در پوشهٔ `image-poc` برای آزمودن تولید تصویر آفلاین با MediaPipe Image Generator ساخته می‌شود؛ این API منسوخ‌شده و فقط برای ارزیابی است، نه معماری نهایی محصول. APK تصویر مدل را درون خود ندارد؛ مدل حدود ۲٫۱ GB جداگانه و پس از نصب دانلود می‌شود. جزئیات و محدودیت‌های مدل در [راهنمای POC تصویر](image-poc/README.md) آمده است.

## دقت اندازه‌گیری و حریم خصوصی

- PSS، کل RAM مصرفی گوشی نیست؛ سهم حافظهٔ فرایند اپ را تقریبی نشان می‌دهد. مقدار «RAM قابل‌مشاهده برای Android» را نیز در بالای صفحه نمایش می‌دهیم. RAM فیزیکی اعلام‌شدهٔ ۱۲ GB با RAM مجازی/Memory Extension یکی نیست.
- وضعیت حرارتی، دسته‌بندی سیستم Android است؛ درصد باتری اندازه‌گیری دقیق mAh نیست. این نمونه جایگزین ابزار آزمایشگاهی نیست.
- خروجی و گزارش فقط در حافظهٔ اپ تا زمان کپی‌کردن نگه داشته می‌شوند. هیچ متن یا telemetry به سرور ارسال نمی‌شود. دسترسی اینترنتی اپ فقط برای دریافت انتخابی وزن مدل از HTTPS است.
- این پروژه هیچ اتصال، توکن یا دکمهٔ انتشار Instagram، Eitaa، Rubika یا Telegram ندارد. هر محتوای تولیدشده صرفاً پیش‌نویس است.
