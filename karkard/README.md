# کارکرد ماهانه

تولید خودکار فرم اکسل «شرح فعالیت روزانه» نیروهای خرید خدمت مرکز فضای مجازی بسیج استان اصفهان.

## نصب

```bash
pip install -r requirements.txt
```

## اجرا

**حالت تعاملی** (سؤال‌وجواب قدم‌به‌قدم):

```bash
python karkard.py
```

**حالت آرگومانی برای یک ماه:**

```bash
python karkard.py --month 5 --year 1405 --name "محسن ابوطالبیان" --title برادر
```

**تولید چند ماه یا کل سال:**

```bash
python karkard.py --months 5,6,7 --year 1405
python karkard.py --months 1-12 --year 1405
python karkard.py --all-months --year 1405
```

ماه را می‌توان به‌صورت عدد (`5`) یا نام (`مرداد`) داد.

| گزینه | پیش‌فرض | توضیح |
|---|---|---|
| `--month` | — | شماره یا نام ماه برای تولید تک‌ماه |
| `--months` | — | فهرست یا بازه ماه‌ها؛ مثل `5,6,مهر` یا `1-12` |
| `--all-months` | خاموش | تولید همه ۱۲ ماه سال |
| `--year` | 1405 | سال |
| `--name` | محسن ابوطالبیان | نام و نام خانوادگی |
| `--title` | برادر | برادر / خواهر |
| `--seed` | تصادفی | بذر تصادفی؛ با seed یکسان، خروجی عیناً تکرار می‌شود |
| `--factor` | تصادفی ۱٫۱۰ تا ۱٫۲۰ | ضریب ثابت اضافه‌کار نسبت به موظفی |
| `--factor-min/--factor-max` | ۱٫۱۰ / ۱٫۲۰ | بازه ضریب تصادفی |
| `--thursday-mode` | half | وضعیت پنجشنبه‌ها: `half` نیمه‌وقت (۴ ساعت) / `full` کامل / `off` تعطیل |
| `--font` | B Nazanin | فونت اکسل (باید روی سیستم نصب باشد) |
| `--show-duty` | خاموش | نمایش سطر موظفی و اضافه‌کار در انتهای جدول |
| `--output` | `output/کارکرد-[ماه]-[سال].xlsx` | مسیر فایل خروجی برای تولید تک‌ماه |
| `--output-dir` | `output/` | پوشه خروجی برای تولید چندماهه |

## منطق محاسبات

- **موظفی روزانه:** ۷ ساعت و ۳۳ دقیقه (۴۵۳ دقیقه)؛ پنجشنبه نیمه‌وقت ۴ ساعت.
- **موظفی ماه** = روزهای کامل × ۴۵۳ + پنجشنبه‌های کاری × ۲۴۰ (جمعه‌ها و تعطیلات رسمی کسر می‌شوند).
- **تعطیلات** بدون ساعت کار ثبت می‌شوند و گزینه دورکاری کاملاً حذف شده است.
- **هدف ماه** = موظفی × ضریب تصادفی ۱٫۱۰ تا ۱٫۲۰؛ توزیع روزانه بین ۷:۴۵ تا ۹:۱۵ (رُند به ۵ دقیقه) و سپس تنظیم دقیق به هدف.
- **ساعت ورود** تصادفی بین ۸:۰۰ تا ۹:۳۰؛ خروج = ورود + جمع روزانه.
- در یکی از روزهای ۲ تا ۷ هر ماه، شرح «تجمیع و تکمیل گزارش کارکرد ماه قبل» درج می‌شود.
- **شرح روزانه** = یک روتین چرخشی + فعالیت‌های بدون تکرار از بانک شرح فعالیت + چرخش ۳۲ ناحیه؛ روزهای اول ماه «جمع‌آوری گزارش ماه قبل» و روزهای پایانی «صدور کارنامه».
- اسکریپت در پایان تضمین می‌کند متن کامل هیچ سلول شرح فعالیت عیناً تکراری نباشد.
- جمعه‌ها: «جمعه (تعطیل هفتگی)» ـ تعطیلات رسمی: «تعطیل رسمی (نام مناسبت)».

## پایگاه داده‌ها (`data/`)

- `holidays.json`: تعطیلات رسمی ۱۴۰۴ تا ۱۴۰۶ (۱۴۰۵ کامل با time.ir راستی‌آزمایی شده؛ ۱۴۰۶ تخمینی است).
- `activities.json`: بانک جملات شرح فعالیت (روتین، رصد و پایش، تولید محتوا، انتشار، تیم‌سازی، اول/آخر ماه).
- `regions.json`: ۳۲ ناحیه استان اصفهان.

## به‌روزرسانی تعطیلات سال‌های بعد

```bash
pip install holidays hijri-converter
python tools/update_holidays.py --years 1404 1405 1406 1407
```

> تعطیلات قمری سال‌های آینده تخمینی است؛ حتماً با تقویم رسمی (time.ir) کنترل و در صورت نیاز `holidays.json` را دستی اصلاح کنید.
