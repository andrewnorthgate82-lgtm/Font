# فایل‌های دانش‌نامهٔ چیستا — یک فایل برای هر حوزه

هر فایل `{id}.md` دانش‌نامهٔ کامل یک حوزه است و مستقلاً قابل‌ویرایش و
جایگزینی است. راهنمای ویرایش داخل خود هر فایل آمده است.

| فایل | حوزه |
|------|------|
| `general.md` | عمومی |
| `marketing.md` | بازاریابی و تبلیغات |
| `social_media.md` | شبکه‌های اجتماعی و سناریو ویدیو |
| `programming.md` | برنامه‌نویسی و نرم‌افزار |
| `copywriting_sales.md` | کپی‌رایتینگ و فروش |
| `education_teaching.md` | آموزش و تدریس |
| `ai_image.md` | تولید تصویر با هوش مصنوعی |
| `ai_video.md` | تولید ویدیو با هوش مصنوعی |
| `writing_translation.md` | نگارش، ویرایش و ترجمه |
| `research_analysis.md` | پژوهش و تحلیل |
| `business_strategy.md` | کسب‌وکار و استراتژی |
| `data_analysis.md` | تحلیل داده |
| `productivity.md` | بهره‌وری و زندگی روزمره |

## طرز کار

1. فایل یک حوزه را به هوش مصنوعی بده و بگو: «این فایل را طبق راهنمای
   ابتدای خودش کامل‌تر و حرفه‌ای‌تر کن و با همان قالب برگردان.»
2. خروجی را ذخیره کن (نام فایل مهم نیست، محتوا مهم است).
3. فایل‌های ویرایش‌شده را برگردان — هر تعداد که بود. هر حوزه‌ای که برنگردد،
   همان نسخهٔ فعلی می‌ماند. حوزهٔ جدید هم می‌توانی اضافه کنی.
