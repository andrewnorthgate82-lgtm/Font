# سامانه جامع مانیتورینگ، تجمیع عملکرد و نمره‌دهی دوره‌ای نواحی نسرا - استان اصفهان

این مخزن شامل سامانه‌های یکپارچه و بهینه‌سازی‌شده ارزیابی عملکرد شهرستان‌های استان اصفهان (۳۲ ناحیه و ۲۲۹ حوزه مقاومت) در نهضت سواد رسانه‌ای انقلاب اسلامی (نسرا) می‌باشد.

## 📁 ساختار قرارگیری فایل‌های گزارش شهرستان‌ها

فایل‌های اکسل گزارش عملکرد ارسالی از نواحی (نظیر گلپایگان، درچه، برخوار، کاشان و ...) را در مسیر زیر قرار دهید:

```
reports/
├── تیر/         <--- فایل‌های گزارش ماه تیر
├── مرداد/       <--- فایل‌های گزارش ماه مرداد
└── شهریور/      <--- فایل‌های گزارش ماه شهریور
```

> **نکته:** موتور شناسایی فوق‌هوشمند سامانه به صورت ۵ لایه‌ای نام شهرستان را از **نام فایل** (فارسی، انگلیسی، پیشوند/پسوند)، **پوشه والد**، **نام شیت** و **اسکن سلولی** تشخیص داده و ماه‌های کارنکرده را به طور خودکار شناسایی می‌نماید.

## ⚖️ مدل و اوزان مصوب نمره‌دهی

1. **آموزش حضوری:** ۱۰٪ (ضریب ماهانه ۳۱ نفر به ازای هر حوزه)
2. **آموزش مجازی:** ۳۰٪ (ضریب ماهانه ۲۱۷ نفر به ازای هر حوزه)
   * *استخر مشترک آموزش (۴۰٪):* حضوری و مجازی کسری یکدیگر را تا سقف ۴۰٪ پوشش می‌دهند.
   * *قانون سرریز آموزش (Spillover):* در صورت عبور مجموع آموزش از ۴۰٪، مازاد آن برای جبران کسری بخش «اقدامات خلاقانه» منتقل می‌شود.
3. **اقدامات خلاقانه:** ۵۰٪ (ضریب ماهانه ۶۲ نفر به ازای هر حوزه - دارای سقف قطعی ۵۰٪)
4. **تولیدات رسانه‌ای:** ۱۰٪ (ضریب ماهانه ۳ تولید به ازای هر حوزه - دارای سقف ۱۰٪)

### مقیاس‌های انتخابی نمره‌دهی:
* **مقیاس واقعی (۰ تا ۱۰۰):** عملکرد صفر = نمره ۰ \| تحقق ۱۰۰٪ = نمره ۱۰۰
* **مقیاس استاندارد نسرا (۷۰ تا ۱۰۰):** نمره = ۷۰ + ۳۰ × (درصد تحقق وزنی)
