راهنمای قدم به قدم اجرای اسکریپت کارکرد ماهانه

۱) فایل ZIP را کامل Extract کنید.
   نکته مهم: از داخل خود ZIP اجرا نکنید؛ حتماً اول Extract All بزنید.

۲) اگر ویندوز دارید:
   - برای ساخت یک ماه با سؤال‌وجواب، روی فایل RUN-WINDOWS.bat دوبار کلیک کنید.
   - برای ساخت کل سال ۱۴۰۵، روی فایل RUN-ALL-1405-WINDOWS.bat دوبار کلیک کنید.

۳) اگر مک یا لینوکس دارید:
   - برای ساخت یک ماه، فایل RUN-MAC-LINUX.command را اجرا کنید.
   - برای ساخت کل سال ۱۴۰۵، فایل RUN-ALL-1405-MAC-LINUX.command را اجرا کنید.

۴) اگر Python نصب نبود:
   - از آدرس https://www.python.org/downloads/ نصب کنید.
   - در ویندوز هنگام نصب، گزینه Add python.exe to PATH را حتماً تیک بزنید.

۵) خروجی‌ها کجا ذخیره می‌شوند؟
   - داخل پوشه: karkard/output
   - نام فایل‌ها مثل این است: کارکرد-مرداد-1405.xlsx

۶) اجرای دستی برای ماه دلخواه:
   از داخل پوشه karkard این دستور را اجرا کنید:
   python karkard.py --month مرداد --year 1405

۷) اجرای دستی برای چند ماه:
   python karkard.py --months 5,6,7 --year 1405
   python karkard.py --months 1-12 --year 1405

۸) تنظیمات اصلی داخل فایل اکسل:
   - صفحه A4 عمودی (Portrait)
   - Fit to one page: عرض ۱ و ارتفاع ۱
   - Center on page فعال است
   - ساعت ورود بین ۸:۰۰ تا ۹:۳۰ است
   - دورکاری حذف شده است
   - شرح فعالیت‌ها تکراری نیستند
