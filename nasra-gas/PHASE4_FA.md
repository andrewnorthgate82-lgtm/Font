# فاز ۴ — دوره گزارش ۲۱ تا ۲۰، نقش همکاران، فایل اکسل پنج‌برگه‌ای، انتشار همزمان در چند کانال، نمونه گزارش‌ها، پیشنهاد موضوع، قانون نام مدرس، کپشن جداگانه هر نوع

## نصب (حدود ۵ دقیقه) — ترتیب مهم است
1. در ویرایشگر Apps Script این **۹ فایل** را هر کدام عوض کن (Ctrl+A ← Delete ← نسخه تازه را بچسبان ← 💾):
   **Config**، **Caption**، **Setup**، **ReportForm**، **Review**، **Telegram**، **Admin**، **Automation**، **Tests**
2. فایل **Setup** ← تابع **`checkInstall`** ← **Run** ← باید ببینی: «✅ همه 12 فایل کامل و نسخه تازه‌اند». اگر ❌ آمد، همان فایلی را که نام برده دوباره کامل بچسبان.
3. بالای ویرایشگر تابع **`installPhase4`** را انتخاب کن ← **Run**
   - ✅ در Execution log باید ببینی: «فاز ۴ نصب شد»، دوره فعلی (مثلاً «گزارش آبان 1405 — برنامه‌های از 1405/07/21 تا 1405/08/20») و تعداد همکاران بدون نقش
   - این کار یک ستون **position** به برگه Users (با فهرست کشویی نقش‌ها) و دو ستون **submitter_position** و **extra_channel_msgs** به برگه Reports سه ستون **class_sub**، **link** و **form_v** به برگه Reports اضافه می‌کند و یک برگه تازه **Samples** (نمونه گزارش‌ها) می‌سازد. به ستون‌های قبلی دست نمی‌زند.
4. فایل **Tests** را باز کن ← تابع **`runTests`** ← Run ← باید ببینی: **27 passed**
5. **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy**

> اجازه تازه‌ای (Authorization) لازم نیست.

## ۱) قانون دوره گزارش (همه‌جای بات)
گزارش هر ماه = برنامه‌هایی که **تاریخ برگزاری**‌شان از **۲۱ ماه قبل تا ۲۰ همان ماه** است (هر دو روز جزو دوره‌اند):

| گزارش | بازه |
|---|---|
| فروردین | ۲۱ اسفند تا ۲۰ فروردین |
| اردیبهشت | ۲۱ فروردین تا ۲۰ اردیبهشت |
| خرداد | ۲۱ اردیبهشت تا ۲۰ خرداد |
| تیر | ۲۱ خرداد تا ۲۰ تیر |
| مرداد | ۲۱ تیر تا ۲۰ مرداد |
| شهریور | ۲۱ مرداد تا ۲۰ شهریور |
| مهر | ۲۱ شهریور تا ۲۰ مهر |
| آبان | ۲۱ مهر تا ۲۰ آبان |
| آذر | ۲۱ آبان تا ۲۰ آذر |
| دی | ۲۱ آذر تا ۲۰ دی |
| بهمن | ۲۱ دی تا ۲۰ بهمن |
| اسفند | ۲۱ بهمن تا ۲۰ اسفند |

این قانون روی این‌ها اعمال می‌شود: عدد «تاییدشده‌ها» در پنل، **📊 آمار ماهانه**، **فایل اکسل**، **یادآوری به شهرستان‌های بدون گزارش**، و **خلاصه خودکار** (که حالا **روز ۲۱** هر ماه، بعد از پایان دوره، برای سوپرادمین می‌آید).
کپشن کانال عوض نشده: خط «🗓 ماه» همان ماه تقویمیِ تاریخ برگزاری است.

روزهای یادآوری اگر همان پیش‌فرض قبلی (`20,27`) بود، خودکار شد **`15,18`** (۵ و ۲ روز مانده به پایان دوره). در برگه Settings، کلید `reminder_days` قابل تغییر است.

## ۲) نقش همکاران
پنج نقش در هر شهرستان:
- مسئول فضای مجازی
- فرمانده گردان خواهر، مسئول نسرا خواهر
- فرمانده گردان برادر، مسئول نسرا برادر

**خواهر/برادر بودن هر گزارش از نقش فرستنده‌اش تعیین می‌شود.** گزارش‌های «مسئول فضای مجازی» و همکاران بدون نقش فقط در «تجمیعی» و «همه شهرستان‌ها» می‌آیند.

نقش را از هر کدام از این سه راه می‌شود گذاشت:
1. **خود همکار:** همکاری که نقش ندارد، با زدن «📝 ارسال گزارش» یک بار نقشش را از ۵ دکمه انتخاب می‌کند و بعد فرم شروع می‌شود. بعد از آن فقط ادمین می‌تواند نقش را عوض کند.
2. **پنل:** `/admin` ← 👤 کاربران ← جستجو ← کارت کاربر ← **🎖 تعیین نقش**
3. **شیت:** برگه Users، ستون **position** ← از فهرست کشویی انتخاب کن (حداکثر ۵ دقیقه بعد در بات اعمال می‌شود؛ برای فوری، `/reload`).

هر گزارش نقشِ فرستنده را **در لحظه ارسال** نگه می‌دارد. پس اگر بعداً نقش کسی عوض شود، گزارش‌های قبلی‌اش جابه‌جا نمی‌شوند. گزارش‌های قدیمیِ قبل از این نسخه از نقش فعلی فرستنده پیروی می‌کنند.

## ۳) فایل اکسل
مسیر: `/admin` ← **📊 آمار ماهانه** ← **📥 فایل اکسل** ← **انتخاب ماه** (۱۲ ماه اخیر؛ «ماه‌های قدیمی‌تر» برای قبل‌تر) ← یکی از دو گزینه:
- **🗂 همه شهرستان‌ها:** گزارش کامل این دوره، همه شهرستان‌ها
- **🏙 یک شهرستان** ← انتخاب شهرستان (عدد داخل پرانتز = تاییدشده‌های دوره) ← **خواهر** / **برادر** / **تجمیعی**

فایل **۵ برگه** دارد، مثل فایل نمونه. هر گزارش بر اساس هشتگ «نوع کلاس/برنامه» در برگه خودش می‌رود:

| برگه | هشتگ | ستون‌ها |
|---|---|---|
| سوادرسانه حضوری | #حضوری | ردیف، تاریخ، نام ناحیه، موضوع، نام سخنران / مدرس، مدت (دقیقه)، تعداد نفرات، مکان برگزاری، لینک مستندات |
| سوادرسانه مجازی (لایو) | #مجازی | همان، با «بستر برگزاری» به‌جای «مکان برگزاری» |
| توانمندسازی گردان | #توانمندسازی | ردیف، تاریخ، برگزار کننده، موضوع، نام سخنران / مدرس، مدت، تعداد نفرات، مکان برگزاری، لینک مستندات، نوع کلاس |
| سواد رسانه خلاقانه | #خلاقانه | ردیف، تاریخ، ناحیه برگزار کننده، موضوع، تعداد نفرات / تعداد بازدید، بستر برگزاری، لینک مستندات |
| تولیدات | #تولیدات | ردیف، تاریخ محتوای تولید شده، تولید کننده، موضوع، نام تولید کننده محتوا، نوع تولید محتوا، تعداد صفحات، لینک مستندات |

- «لینک مستندات» = لینک پست همان گزارش در کانال (قابل کلیک؛ اگر کانال خصوصی باشد فقط برای اعضای کانال باز می‌شود).
- «بستر برگزاری» = همان متنی که همکار در قدم «بستر / مکان برگزاری» نوشته است.
- «برگزار کننده» و «تولید کننده» = نام شهرستان. «نام تولید کننده محتوا» = همان «مدرس/سخنران» فرم.
- **ستون‌هایی که فرم بات نمی‌پرسد خالی می‌مانند** تا دستی پر شوند: «نوع کلاس» (توانمندسازی)، «نوع تولید محتوا» و «تعداد صفحات» (تولیدات).
- ردیف‌ها به ترتیب تاریخ برگزاری هستند. ظاهر فایل مثل نمونه است: قلم B Titr، سطر عنوان طلایی، کادر نازک، راست‌به‌چپ، و سطر عنوان هنگام پایین رفتن ثابت می‌ماند.

## ۴) انتشار همزمان در چند کانال
کانال اصلی همان کانال فعلی است و لینک‌های فایل اکسل هم به همان است. می‌توانی هر تعداد کانال اضافه کنی:

1. بات را در کانال جدید **ادمین** کن، با اجازه‌های **ارسال**، **ویرایش** و **حذف** پیام (Post / Edit / Delete messages).
2. `/admin` ← **📡 کانال‌ها** (فقط سوپرادمین) ← **➕ افزودن کانال**
3. یکی از این دو کار را بکن:
   - **کانال عمومی:** آیدی‌اش را بفرست، مثل `@channel_name` یا لینک `t.me/channel_name`
   - **کانال خصوصی:** یک پست از همان کانال را همین‌جا **فوروارد** کن
4. بات یک پیام آزمایشی در کانال می‌فرستد، ویرایشش می‌کند و پاکش می‌کند. ✅ «کانال … اضافه شد»

از این به بعد:
- هر گزارشی که در گروه ادمین‌ها **تایید** شود، **همزمان** با همان عکس‌ها و همان کپشن در همه کانال‌ها منتشر می‌شود.
- **ویرایش کپشن** و **حذف از کانال** در پنل، روی همه کانال‌ها اعمال می‌شود.
- اگر انتشار در یک کانال اضافه ناموفق باشد (مثلاً بات آن‌جا ادمین نیست)، گزارش باز هم در کانال اصلی منتشر می‌شود و در گروه ادمین‌ها هشدار می‌آید.
- گزارش‌هایی که قبل از اضافه شدن کانال منتشر شده‌اند، در کانال تازه فرستاده نمی‌شوند.
- برداشتن کانال: 📡 کانال‌ها ← 🗑 برداشتن. پست‌های قبلی آن‌جا می‌مانند.
- `/status` وضعیت کانال‌های اضافه را هم نشان می‌دهد.

## ۵) منوی همکاران و «📚 نمونه گزارش‌ها»
منوی پایین صفحه همکاران حالا این است:

| 📝 ارسال گزارش | 📚 نمونه گزارش‌ها |
|---|---|
| 📋 گزارش‌های من | 👨‍🏫 مدرسان من |

- «📝 ارسال گزارش» همان «ثبت گزارش جدید» قبلی است. اگر همکاری هنوز کیبورد قدیمی را دارد، دکمه قدیمی هم کار می‌کند.
- کیبورد تازه با `/start`، بعد از ارسال گزارش بعدی، با یادآوری روز ۱۵، یا با **پیام همگانی** به گوشی همکاران می‌رسد. پیشنهاد: بعد از ثبت نمونه‌ها، از 📣 پیام همگانی یک پیام کوتاه بفرست (مثلاً «دکمه 📚 نمونه گزارش‌ها اضافه شد؛ قبل از ارسال گزارش ببینید»). منوی همه همان لحظه عوض می‌شود.
- «📚 نمونه گزارش‌ها» ← ۵ دکمه **حضوری، مجازی، توانمندسازی، خلاقانه، تولیدات** ← بات همان پستی را که ادمین برای آن نوع ثبت کرده می‌فرستد.

**ثبت یا عوض کردن نمونه (هر ادمین، بدون دست زدن به کد):**
1. `/admin` ← **📚 نمونه گزارش‌ها** ← وضعیت هر ۵ نوع را می‌بینی (✅ ثبت شده / ⚪️ هنوز ثبت نشده)
2. روی یک نوع بزن (مثلاً حضوری) ← **✏️ ثبت نمونه**
3. پست آموزشی را **همان‌جا در چت بات** بفرست، یا یک پست خوب را **از کانال فوروارد کن**:
   - متن، عکس، آلبوم چندعکسی، ویدیو، گیف یا فایل. کپشن و قالب‌بندی (پررنگ، لینک، هشتگ) عیناً حفظ می‌شود.
   - می‌توانی چند پیام پشت هم بفرستی؛ مثلاً اول یک متن توضیحی، بعد آلبوم گزارش (حداکثر ۱۰ مورد).
   - ✅ بعد از هر پیام (برای آلبوم فقط یک بار) بات می‌نویسد «📥 دریافت شد».
4. **✅ ذخیره** ← بات دقیقاً همان چیزی را که همکاران خواهند دید برایت می‌فرستد.
- **❌ انصراف**: نمونه قبلی دست نمی‌خورد.
- **👁 پیش‌نمایش** و **🗑 حذف نمونه** روی کارت هر نوع هست.
- خود محتوا در برگه **Samples** ذخیره می‌شود؛ اگر پست کانال پاک شود، نمونه از بین نمی‌رود.
- ⚠️ ایموجی‌های متحرک مخصوص تلگرام پریمیوم در نمونه به ایموجی ساده تبدیل می‌شوند (محدودیت تلگرام برای بات‌ها).

## ۶) فرم گزارش: متن قدم عکس، پیشنهاد موضوع، نام مدرس
- **قدم ۱ (عکس‌ها):** «۱ تا ۵ عکس از برنامه را بفرستید (تکی یا آلبوم). حتماً بنر نماد نسرا به همراه موضوع و تاریخ در تصاویر باشد.»
- **قدم ۴ (موضوع):** ۶ دکمه پیشنهادی هست: سواد رسانه عمومی، توانمندسازی گردان سایبری، جنگ شناختی، آموزش اینستاگرام، آموزش توییتر، آموزش نرم افزارهای موبایلی. اگر موضوع چیز دیگری است، همکار خودش می‌نویسد و می‌فرستد.
- **مدرس جدید:** فقط **نام و نام خانوادگی**؛ بدون عنوان، لقب، مسئولیت، درجه یا رتبه (✅ حامد کمال — ❌ دکتر کمال، آقای کمال، دکتر حامد کمال).
  - بات این را هنگام «➕ مدرس جدید» می‌گوید و خودش هم بررسی می‌کند. اگر نام لقب داشته باشد (دکتر، مهندس، آقای، خانم، حاج، حجت‌الاسلام، سرهنگ، مسئول، مدیر و…)، یک‌کلمه‌ای باشد یا عدد و پرانتز داشته باشد، علت را می‌گوید و دوباره می‌پرسد.
  - «سید» لقب حساب نمی‌شود چون معمولاً جزء نام است.
  - همین قانون در پنل ادمین هم هست (افزودن مدرس، تغییر نام مدرس، ویرایش مدرس گزارش).
  - مدرسانی که **قبلاً** با لقب ثبت شده‌اند خودکار عوض نمی‌شوند. از `/admin` ← 👨‍🏫 مدرسان ← شهرستان ← مدرس ← ✏️ تغییر نام درستشان کن.

## ۷) کپشن و قدم‌های جداگانه برای هر نوع برنامه
همکار بعد از عکس‌ها نوع برنامه را انتخاب می‌کند. از آن به بعد فقط سؤال‌های **همان نوع** پرسیده می‌شود و شماره قدم‌ها («قدم ۴ از ۸») برای هر نوع درست است.

| نوع | قدم‌ها (بعد از عکس و نوع) | تعداد کل |
|---|---|---|
| حضوری | نام عملیات، موضوع، مدرس، تاریخ برگزاری، ساعت، مدت، تعداد، مخاطبین، مکان | ۱۱ |
| مجازی | موضوع، مدرس، تاریخ برگزاری، مدت، تعداد، مخاطبین، بستر برگزاری، لینک برگزاری | ۱۰ |
| توانمندسازی | **حضوری یا مجازی** ← حضوری: دقیقاً مثل حضوری ؛ مجازی: مثل مجازی + ساعت | ۱۲ |
| خلاقانه | **بخش خلاقانه** (۷ بخش)، موضوع، تاریخ انتشار، تعداد بازدید، بستر انتشار، لینک پست | ۸ |
| تولیدات | **نوع محتوا** (۷ نوع)، تولید کننده (از فهرست مدرسان)، موضوع محتوا | ۵ |

- **بخش‌های خلاقانه:** #انتشار_شبکه_اجتماعی، #چاپ_بنر، #بروشور، #نماز_جمعه، #نمایشگاه، #تلویزیون_شهری، #صدا_و_سیما
- **نوع محتوای تولیدات:** #صفحه_word، #اسلاید، #کلیپ، #موشن_گرافیک، #اینفوگرافیک، #پوستر، #سایر
- **بستر برگزاری مجازی:** دکمه‌های اسکای روم، ایتا، بله، روبیکا، آپارات، اینستاگرام. همکار می‌تواند بستر دیگری را هم بنویسد.
- **بستر انتشار خلاقانه:** برای «انتشار شبکه اجتماعی» دکمه شبکه‌ها نمایش داده می‌شود؛ برای بنر، بروشور، نمایشگاه و… همکار محل یا شبکه را می‌نویسد.
- **لینک:** همکار لینک را می‌فرستد یا «ندارد» را می‌زند (در کپشن: «ندارد»). متن بی‌ربط به‌جای لینک پذیرفته نمی‌شود.
- **تولیدات تاریخ نمی‌پرسد:** تاریخ گزارش = روز ارسال. این تاریخ برای دوره ۲۱ تا ۲۰، خط «ماه» کپشن و ستون «تاریخ محتوای تولید شده» در اکسل به کار می‌رود.
- **ایموجی‌ها یکدست شدند:** هر خط در همه کپشن‌ها همیشه همان ایموجی را دارد (📅 درج، ✅ استان و معاونت، 🗓 ماه، 📍 ناحیه، ⭕️ نوع، 💢 عملیات، 📄 موضوع، 👨‍🏫 مدرس/تولید کننده، 📆 تاریخ برگزاری/انتشار، ⏰ ساعت، ⏳ مدت، 🚻 شرکت‌کننده، 👁 بازدید، 👥 مخاطبین، 🏫 مکان، 💻 بستر برگزاری، 📢 بستر انتشار، 🔗 لینک، 🎞 نوع محتوا).
- **ویرایش در پیش‌نمایش:** دکمه‌های ویرایش فقط بخش‌های همان نوع را نشان می‌دهند. اگر همکار نوع (یا حضوری/مجازی) را عوض کند، فقط بخش‌های تازه پرسیده می‌شود و موضوع، مدرس و عکس‌ها می‌مانند.
- **پنل ادمین (✏️ ویرایش کپشن):** دکمه‌ها هم مخصوص همان نوع‌اند (مثلاً برای خلاقانه: بخش خلاقانه، تعداد بازدید، بستر انتشار، لینک پست). با تغییر نوع به خلاقانه/تولیدات/توانمندسازی، بات بخش یا نوع محتوا را هم می‌پرسد.
- **اکسل:** ستون «نوع کلاس» برگه توانمندسازی (حضوری/مجازی) و «نوع تولید محتوا» برگه تولیدات خودکار پر می‌شوند. در برگه خلاقانه، بخش هم کنار بستر می‌آید (مثلاً «چاپ بنر — میدان امام»).
- **آمار ماهانه:** بازدیدهای خلاقانه جزو «نفر شرکت‌کننده» حساب نمی‌شوند و جدا نوشته می‌شوند.
- **گزارش‌های قبلی** دست نمی‌خورند. اگر ادمین یکی را ویرایش کند، با همان قالب قبلی ویرایش می‌شود. گزارش ردشده قدیمی موقع «اصلاح و ارسال مجدد» با فرم تازه باز می‌شود و فقط بخش‌های تازه‌اش (مثلاً لینک) پرسیده می‌شود.

## تست بعد از نصب
1. `/admin` ← پنل باید بنویسد «تاییدشده‌های گزارش آبان 1405 (از 1405/07/21 تا 1405/08/20): …»
2. 📊 آمار ماهانه ← عنوان «گزارش آبان 1405» و خط «خواهران: … — برادران: … — فضای مجازی: …»
3. 📥 فایل اکسل ← آبان 1405 ← 🗂 همه شهرستان‌ها ← فایل «گزارش آبان 1405 - همه شهرستان‌ها.xlsx» می‌آید؛ در Excel باید ۵ برگه پایین صفحه ببینی.
4. 📥 فایل اکسل ← آبان 1405 ← 🏙 یک شهرستان ← یک شهرستان ← خواهر ← فایل «… - خواهران.xlsx»
5. با حساب کارمند آزمایشیِ بدون نقش «📝 ارسال گزارش» را بزن ← باید ۵ دکمه نقش بیاید ← یکی را بزن ← فرم عادی شروع شود.
6. کارت همان کاربر در پنل ← «نقش: …» و دکمه 🎖 تعیین نقش
7. 📡 کانال‌ها ← ➕ افزودن کانال ← آیدی کانال دوم ← «اضافه شد» ← یک گزارش آزمایشی را تایید کن ← باید در **هر دو** کانال بیاید.
8. `/admin` ← 📚 نمونه گزارش‌ها ← حضوری ← ✏️ ثبت نمونه ← یک پست کانال را فوروارد کن ← «📥 دریافت شد» ← ✅ ذخیره ← همان پست برایت می‌آید. بعد با حساب کارمند آزمایشی: 📚 نمونه گزارش‌ها ← حضوری ← همان پست باید بیاید؛ «مجازی» (ثبت‌نشده) ← پیام «هنوز توسط ادمین ثبت نشده است».
9. با حساب کارمند آزمایشی: 📝 ارسال گزارش ← متن تازه قدم ۱ ← … ← قدم ۴ باید ۶ دکمه موضوع داشته باشد ← «جنگ شناختی» ← قدم ۵ ← ➕ مدرس جدید ← «دکتر کمال» بنویس ← باید رد شود ← «حامد کمال» ← پذیرفته شود.
10. با حساب کارمند آزمایشی از هر ۵ نوع یک گزارش بفرست (برای توانمندسازی هر دو حالت حضوری و مجازی). در هر کدام شماره قدم‌ها و کپشن پیش‌نمایش را با جدول بخش ۷ مقایسه کن. یکی را تایید کن ← کپشن کانال هم باید همان باشد.
