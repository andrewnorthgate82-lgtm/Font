# فاز ۳ — کارهای خودکار: بکاپ شبانه، یادآوری‌ها، پیام همگانی، فایل اکسل

## نصب (حدود ۱۰ دقیقه) — ترتیب مهم است
1. ویرایشگر Apps Script ← **＋** ← **Script** ← اسم: `Automation` ← محتوای پیش‌فرض را پاک کن ← کل **Automation.gs** را بچسبان ← 💾
2. فایل‌های **Admin**، **Setup** و **Tests** را هر کدام: Ctrl+A ← Delete ← نسخه تازه را بچسبان ← 💾
3. بالای ویرایشگر تابع **`installPhase3`** را انتخاب کن ← **Run**
   - پنجره **Authorization required** می‌آید (چون بکاپ به Google Drive نیاز دارد) ← Review permissions ← حسابت ← Advanced ← Go to … (unsafe) ← **Allow**
   - ✅ در Execution log باید ببینی: «فاز ۳ نصب شد»، اسم اولین بکاپ و لینک پوشه بکاپ‌ها
4. تابع **`runTests`** ← Run ← باید ببینی: **20 passed**
5. فقط بعد از قدم ۳: **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy**
6. در بات: `/status` ← باید ببینی «آخرین بکاپ: … ✅» و «بکاپ شبانه و کارهای روزانه: فعال ✅»

> ⚠️ اگر قدم ۵ را قبل از قدم ۳ (اجازه Drive) انجام بدهی، ممکن است بات تا وقتی اجازه را ندهی جواب ندهد. اگر این اتفاق افتاد: installPhase3 را Run و Allow کن، دوباره New version بزن.

## چه چیزی خودکار شد
| چه | کِی | به چه کسی |
|---|---|---|
| 💾 بکاپ کامل شیت در پوشه «Nasra Bot Backups» در Drive | هر شب ساعت ۳ | — (فقط ۱۴ بکاپ آخر نگه داشته می‌شود) |
| ⚠️ خبر شکست بکاپ | اگر بکاپ نشد | سوپرادمین |
| 🔔 یادآوری به شهرستان‌های بدون گزارش در ماه جاری | روز ۲۰ و ۲۷ هر ماه، ساعت ۱۰ | همکاران فعال همان شهرستان‌ها + خلاصه برای سوپرادمین |
| ⏰ گزارش‌هایی که بیش از ۲۴ ساعت بررسی نشده‌اند | هر روز ساعت ۱۰ | گروه بررسی |
| 🗓 خلاصه آمار + فایل اکسل ماه قبل | روز اول هر ماه | سوپرادمین |

## در پنل /admin
- **📊 آمار ماهانه ← 📥 فایل اکسل همین ماه** (همه ادمین‌ها): فایل Excel واقعی (.xlsx)، راست‌به‌چپ، با ۸ ستون جدا: تاریخ برگزاری، ناحیه برگزار کننده، موضوع، نام سخنران یا مدرس، مدت زمان کلاس، تعداد نفرات، مکان برگزاری، لینک منتشرشده در کانال (قابل کلیک). اگر کانال خصوصی باشد، لینک فقط برای اعضای کانال باز می‌شود.
- **📣 پیام همگانی** (فقط سوپرادمین): همه همکاران فعال / یک شهرستان / فقط ادمین‌ها ← نوشتن متن ← پیش‌نمایش ← ارسال. ارسال در پس‌زمینه انجام می‌شود (تا ۱–۲ دقیقه بعد شروع می‌شود) و در پایان تعداد موفق/ناموفق گزارش می‌شود.
- **💾 بکاپ و خودکارها** (فقط سوپرادمین): وضعیت همه کارهای خودکار، **بکاپ همین الان**، **پیش‌نمایش یادآوری** (فقط برای خودت، بدون ارسال به کسی)، روشن/خاموش‌کردن یادآوری ماهانه.

## تنظیم دلخواه (برگه Settings)
| key | پیش‌فرض | معنی |
|---|---|---|
| `reminder_days` | `20,27` | روزهای ماه شمسی برای یادآوری |
| `reminder_enabled` | `1` | `0` = یادآوری خاموش |
| `pending_alert_hours` | `24` | `0` = هشدار گزارش معطل خاموش |
| `backup_keep` | `14` | تعداد بکاپ‌های نگه‌داشته‌شده (حداقل ۳) |

## بازگردانی از بکاپ (اگر روزی شیت خراب شد)
1. Drive ← پوشه «Nasra Bot Backups» ← آخرین بکاپ سالم را باز کن.
2. در شیت اصلی، برگه خراب را پاک کن؛ در بکاپ روی همان برگه راست‌کلیک ← **Copy to ← Existing spreadsheet** ← شیت اصلی.
3. نام برگه کپی‌شده را دقیقاً مثل قبل کن (مثلاً `Reports`، بدون «Copy of»).
4. در بات `/reload` بزن.
(شیت اصلی را با بکاپ «جایگزین» نکن؛ چون SPREADSHEET_ID به همان فایل اصلی اشاره می‌کند.)

## تست پذیرش فاز ۳
1. `/admin` ← 💾 بکاپ و خودکارها ← همه سطرها ✅ ← **بکاپ همین الان** ← پیام «بکاپ گرفته شد» + لینک پوشه.
2. **پیش‌نمایش یادآوری** ← فهرست شهرستان‌های بدون گزارش و متن نمونه فقط برای خودت می‌آید.
3. 📊 آمار ماهانه ← 📥 فایل اکسل ← فایل `.xlsx` در چت می‌آید؛ در Excel هر ستون جدا و راست‌به‌چپ است و لینک‌ها کلیک می‌شوند.
4. 📣 پیام همگانی ← **فقط ادمین‌ها** ← «تست» ← ارسال ← چند دقیقه بعد پیام «ارسال شد، موفق: …».
