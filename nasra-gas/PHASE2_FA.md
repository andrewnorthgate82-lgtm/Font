# فاز ۲ — پنل مدیریت داخل بات (/admin)

## نصب (حدود ۵ دقیقه)
1. ویرایشگر Apps Script ← کنار Files روی **＋** ← **Script** ← اسم را `Admin` بگذار (خودش `.gs` می‌شود) ← محتوای پیش‌فرض را پاک کن ← کل **Admin.gs** را بچسبان ← 💾
2. فایل **Telegram** ← Ctrl+A ← Delete ← کل **Telegram.gs** تازه را بچسبان ← 💾
3. فایل **Tests** ← Ctrl+A ← Delete ← کل **Tests.gs** تازه را بچسبان ← 💾
4. بالای ویرایشگر تابع `runTests` را انتخاب کن ← **Run** ← در Execution log باید ببینی: **16 passed**
5. **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy** (آدرس عوض نمی‌شود)
6. در بات بنویس: `/admin`

هیچ برگه، Secret، Worker یا وبهوکی عوض نمی‌شود. `setup` لازم نیست.

## بخش‌های پنل
| دکمه | کار |
|---|---|
| ⏳ در انتظار بررسی | فهرست گزارش‌هایی که هنوز در گروه تایید/رد نشده‌اند |
| 📢 منتشرشده‌ها | ۸ گزارش آخرِ منتشرشده ← ✏️ ویرایش کپشن در کانال یا 🗑 حذف از کانال |
| 🔎 گزارش با شماره | شماره گزارش (از پیام گروه بررسی) را بفرست تا کارتش بیاید |
| 📊 آمار ماهانه | تعداد گزارش تاییدشده و نفرات هر شهرستان در هر ماه + شهرستان‌های بدون گزارش |
| 👤 کاربران | جستجو با شماره / نام / آیدی ← غیرفعال‌کردن، فعال‌سازی، تغییر شهرستان |
| 👨‍🏫 مدرسان | انتخاب شهرستان ← افزودن، تغییر نام، غیرفعال‌کردن (از فرم کارمندان پنهان می‌شود) |
| 🛡 ادمین‌ها (فقط سوپرادمین) | افزودن ادمین با آیدی عددی (/myid) یا ارسال مخاطب؛ برداشتن دسترسی |

## نکته‌ها
- ویرایش کپشن «تاریخ درج» اصلی را نگه می‌دارد؛ عکس‌ها قابل ویرایش نیستند.
- حذف از کانال: تلگرام معمولاً اجازه حذف پیام‌های **قدیمی‌تر از ۴۸ ساعت** را به بات نمی‌دهد؛ در این صورت بات می‌گوید چند پیام را دستی پاک کنی (وضعیت گزارش به‌هرحال «حذف‌شده» می‌شود).
- ادمین جدید را حتماً **عضو گروه بررسی** هم بکن تا گزارش‌ها را ببیند.
- سوپرادمین از داخل بات حذف نمی‌شود (فقط از برگه Admins).
- برای خروج از هر حالت تایپ: `/cancel` یا دوباره `/admin`.

## تست پذیرش فاز ۲
1. `/admin` ← پنل با عدد «در انتظار» و «تاییدشده این ماه» می‌آید.
2. 📢 منتشرشده‌ها ← گزارش تستی ← ✏️ ← 📄 موضوع ← یک کلمه عوض کن ← پست کانال همان لحظه عوض می‌شود.
3. 📊 آمار ماهانه ← شهرستان تست با ۱ گزارش دیده می‌شود.
4. 👤 کاربران ← شماره کارمند تست ← ⛔️ غیرفعال ← کارمند «📝 ارسال گزارش» بزند ← پیام «حساب شما غیرفعال شده» ← دوباره ✅ فعال کن.
5. 👨‍🏫 مدرسان ← شهرستان تست ← ➕ یک مدرس ← در فرم کارمند دیده شود ← 🚫 غیرفعال ← دیگر دیده نشود.
6. 🗑 حذف از کانال روی پست تستی ← پست از کانال پاک می‌شود و کارمند پیام می‌گیرد.
