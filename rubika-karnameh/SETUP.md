# 🚀 آموزش راه‌اندازی گام‌به‌گام (ویژه‌ی شروع از صفر)

> این راهنما برای کسی نوشته شده که هیچ برنامه‌نویسی بلد نیست.
> هر مرحله را به ترتیب و بدون جا انداختن انجام دهید. کل آماده‌سازی فقط **یک بار** و حدود ۲۰ دقیقه طول می‌کشد.
> برای ارسال ماه‌های بعد، فقط ۵ دقیقه لازم است (بخش D).

**از کجا شروع کنم؟** از همین فایل — روش ۱ (نسخه وب). روش ۲ (ربات) را بعداً وقتی کار راه افتاد فعال کنید.

---

## 🖱 راه ساده‌تر: فایل‌های دابل‌کلیکی (پیشنهادی — از این استفاده کنید!)

از این نسخه به بعد، **هیچ نیازی به تایپ دستور در پنجره‌ی سیاه نیست**. کافی است روی این فایل‌ها دابل‌کلیک کنید:

| فایل | کِی استفاده شود | چه کاری می‌کند |
|---|---|---|
| `1-نصب.bat` | فقط یک بار، اولِ کار | نصب همه‌ی پیش‌نیازها + تست سلامت (خودش همه‌چیز را انجام می‌دهد) |
| `2-تست-به-خودم.bat` | بعد از نصب | یک پیام آزمایشی به خودتان می‌فرستد تا مطمئن شوید همه‌چیز کار می‌کند (شماره‌ی خودتان را اول در اکسل بنویسید) |
| `3-لیست.bat` | قبل از هر ارسال | نشان می‌دهد هر کارنامه برای چه شماره‌هایی می‌رود — **هیچ چیزی ارسال نمی‌کند** |
| `4-ارسال.bat` | هر ماه | ارسال واقعی همه‌ی کارنامه‌ها |
| `5-عیب‌یابی.bat` | اگر خطایی دیدید | فایل‌های عیب‌یابی در پوشه‌ی `debug` می‌سازد تا برای پشتیبان بفرستید |

**نکته‌های مهم:**

- ⚠️ بار اول که یک فایل `.bat` را اجرا می‌کنید، ممکن است ویندوز پیام آبیِ
  «Windows protected your PC» نشان بدهد. روی **More info** و بعد **Run anyway**
  کلیک کنید. این پیام فقط به این دلیل است که فایل از اینترنت دانلود شده؛
  این فایل‌ها فقط چند دستور نصبِ ساده را اجرا می‌کنند و بی‌خطرند.
- اگر آنتی‌ویروس هشدار داد، اجازه‌ی اجرا (Allow) بدهید.
- پنجره‌ی بازشده تا آخر کار باز می‌ماند و آخرش با زدن یک کلید بسته می‌شود.
  وسط کار آن را نبندید.

**چرا پیام‌های داخل پنجره انگلیسی است؟** ویندوز در پنجره‌ی سیاه (cmd) متن فارسی را
روی خیلی از سیستم‌ها به‌صورت علامت سوال (؟؟؟) نشان می‌دهد؛ برای همین پیام‌ها
انگلیسیِ ساده شده‌اند. معنی مهم‌ترین‌ها:

| پیام در پنجره | معنی |
|---|---|
| `[OK]` | انجام شد ✓ |
| `please wait...` | صبر کنید — در حال کار است |
| `[1/3]`، `[2/3]`، `[3/3]` | مرحله‌ی ۱، ۲ و ۳ از ۳ |
| `ALL TESTS PASSED` | همه‌ی تست‌ها پاس شد — نصب کامل است 🎉 |
| `Press any key to continue...` | هر کلیدی بزنید تا ادامه پیدا کند یا بسته شود |
| `[ERROR]` | خطا — متن بعدش را برای پشتیبان تایپ کنید و بفرستید |
| `RESULT: sent=... failed=...` | نتیجه‌ی ارسال: چند پیام رفت، چند تا ناموفق بود |

بقیه‌ی این راهنما، روش دستی (پنجره‌ی سیاه) را هم توضیح می‌دهد — اگر خواستید روش معمول را یاد بگیرید؛ در غیر این صورت با فایل‌های بالا کفایت می‌کند.

## بخش A — نصب پیش‌نیازها (فقط بار اول) — روش دستی

### گام ۱ — نصب پایتون

1. به آدرس **python.org/downloads** بروید و روی دکمه‌ی زردِ بالای صفحه (Download Python 3.x.x) کلیک کنید.
2. فایل دانلود‌شده را اجرا کنید.
3. ⚠️ **مهم‌ترین نکته‌ی کل نصب:** در اولین صفحه، پایینِ پنجره، حتماً تیک
   **«Add python.exe to PATH»** را بزنید و بعد روی **Install Now** کلیک کنید.
4. بعد از پایان نصب، امتحانش کنید:
   - کلید ویندوز را بزنید، تایپ کنید `cmd` و Enter (پنجره‌ی سیاهِ خط فرمان باز می‌شود)
   - تایپ کنید:  `python --version`  و Enter
   - باید جوابی مثل `Python 3.12.8` ببینید ✅
   - اگر نوشت «python is not recognized»، یعنی تیکِ گام ۳ را نزده‌اید: پایتون را حذف (Uninstall) کنید و دوباره با تیک نصب کنید.

> 💡 راه جایگزین (ساده‌تر): در ویندوز، **Microsoft Store** را باز کنید، عبارت `python` را جستجو کنید و «Python 3.x» را نصب کنید. مرحله‌ی تیک زدن هم ندارد.

### گام ۲ — دانلود پوشه‌ی اسکریپت

فایل فشرده‌ی **`rubika-karnameh.zip`** (که کنار همین فایل‌ها هست) را دانلود کنید و محتوایش را در یک پوشه‌ی دائمی Extract کنید.

پیشنهاد: `Documents\rubika-karnameh` — چیزی که داخل دسکتاپِ شلوغ گم شود، بعداً دردسر می‌شود!

بعد از Extract باید این فایل‌ها را ببینید:

```
rubika-karnameh\
 ├─ send_web.py            ← اسکریپت اصلی ارسال (روش ۱)
 ├─ send_bot.py            ← اسکریپت روش ۲ (فعلاً کاری با آن ندارید)
 ├─ test_flow_mock.py      ← تست خودکار
 ├─ config.json            ← تنظیمات
 ├─ README.md              ← راهنمای کامل (مرجع)
 ├─ SETUP.md               ← همین فایل
 ├─ مخاطبین.xlsx           ← دفترچه‌ی شماره‌ی مسئولان (باید پرش کنید)
 ├─ کارنامه‌ها\             ← تصویر تست داخلش هست
 └─ ...
```

### گام ۳ — نصب کتابخانه‌ها

1. با **File Explorer** وارد پوشه‌ی `rubika-karnameh` شوید.
2. روی **نوار آدرس** بالای پنجره کلیک کنید، تایپ کنید: `cmd` و Enter بزنید.
   (پنجره‌ی سیاه در همین پوشه باز می‌شود — مسیر پوشه باید در ابتدای خط نوشته شده باشد.)
3. این دستور را تایپ/کپی کنید و Enter: (کپی در cmd با راست‌کلیک یا Ctrl+V)

   ```
   pip install -U playwright
   ```

   چند دقیقه صبر کنید تا تمام شود (چند خط سبز/زرد می‌آید، اشکالی ندارد).

4. بعد این دستور:

   ```
   playwright install chromium
   ```

   این دستور مرورگر Chromium را دانلود می‌کند (حدود ۱۵۰ مگابایت — یک بار برای همیشه).

> ⚠️ **اگر دستور دوم خطای شبکه/دانلود داد، اصلاً نگران نباشید!**
> اسکریپت به‌صورت خودکار از **گوگل کروم** (و اگر نبود، از Edge خودِ ویندوز) استفاده می‌کند و هیچ کار اضافه‌ای لازم نیست.
> (اگر گلم `pip` را شناخت ولی `playwright` را نه، به‌جای دستور بالا بنویسید: `python -m playwright install chromium`)

### گام ۴ — تست سلامت نصب

در همان پنجره‌ی cmd:

```
python test_flow_mock.py
```

باید در پایان بنویسد: **«همه سناریوهای شبیه‌سازی‌شده پاس شدند!»** ✅ — یعنی نصب سالم است.

## بخش B — آماده‌سازی داده‌ها (هر ماه ~۵ دقیقه)

### گام ۵ — گذاشتن تصاویر کارنامه

1. وارد پوشه‌ی `کارنامه‌ها` شوید.
2. **تصویر تستِ داخلش را حذف کنید** (`کارنامه_ناحیه تست.png`).
3. ۳۲ تصویر کارنامه‌ی واقعی را داخلش کپی کنید.

قاعده‌ی نام‌گذاری — دقیقاً به این شکل:

```
کارنامه_نام ناحیه.png          ← مثال: کارنامه_آران و بیدگل.png
```

- پیشوندِ `کارنامه_` لازم است؛ بعدش نام ناحیه.
- پسوندهای مجاز: `.png` ، `.jpg` ، `.jpeg` ، `.webp` ، `.bmp`
- ⚠️ در نام ناحیه از علامت‌های ` / \ : * ? " < > |` استفاده نکنید (در ویندوز ممنوع هستند).
- اگر نام فایلی از قاعده خارج است، جای نگرانی نیست — فایل `overrides.csv` راه‌حل دستی دارد (توضیح در README).

### گام ۶ — تنظیم ماهِ کپشن

فایل `config.json` را با **Notepad** باز کنید و فقط مقدار `month` را عوض کنید:

```json
"month": "مهر ۱۴۰۵",
```

ذخیره کنید و ببندید. (بقیه‌ی تنظیمات را فعلاً دست نزنید — پیش‌فردها درست است.)

### گام ۷ — پر کردن فایل اکسلِ مخاطبین (مهم‌ترین قدم!)

فایل **`مخاطبین.xlsx`** را دابل‌کلیک کنید (با اکسل باز می‌شود). هر سطر یک ناحیه است:

| نام ناحیه | نام در روبیکا — مسئول نسرا | شماره — مسئول نسرا | نام در روبیکا — فرمانده گردان | شماره — فرمانده گردان | نام در روبیکا — مسئول فضای مجازی | شماره — مسئول فضای مجازی |
|---|---|---|---|---|---|---|
| آران و بیدگل | علی رضایی | 09121112233 | محمد کریمی | 09123334455 | — | 09125556677 |

- **نام ناحیه** (ستون اول) باید دقیقاً مثل نامِ فایل تصویر باشد: تصویر `کارنامه_آران و بیدگل.png` ← در اکسل بنویسید `آران و بیدگل`
- ⭐ **ستون «نام در روبیکا» مهم‌ترین ستون است**: نام هر مسئول را **همان‌طور که در لیست گفتگوهای روبیکای خودتان می‌بینید** بنویسید — ارسال با جستجوی همین نام انجام می‌شود.
- ⚠️ **نکته‌ی مهم:** جستجوی روبیکای وب فقط **گفتگوهای موجود** را پیدا می‌کند. پس فقط کسانی که قبلاً با آن‌ها گفتگو داشته‌اید پیدا می‌شوند؛ برای بقیه **یک بار از گوشی بهشان پیام بدهید** تا گفتگو ساخته شود (بعد از آن همیشگی است).
- **شماره‌ها** را هم بنویسید (برای شناسایی و پشتیبانی)؛ هر شکلی بنویسید (۰۹۱۲… یا +۹۸۹۱۲… یا با خط تیره) خودش درست می‌خواند.
- اگر یک نفر دو نقش دارد، همان نام/شماره را دوبار بنویسید؛ فقط **یک** پیام می‌گیرد.
- ناحیه‌ای که نام یا شماره‌اش را ننویسید، رد می‌شود (خطا نمی‌دهد).
- در پایان **ذخیره کنید و اکسل را ببندید** (اکسل نباید موقع ارسال باز باشد).

## بخش C — تست و ارسال

### گام ۸ — تست اول: لیست بدون ارسال (dry-run)

در پنجره‌ی cmd (داخل پوشه‌ی rubika-karnameh):

```
python send_web.py --dry-run
```

لیست کاملِ «کدام تصویر ← برای چه شماره‌هایی» چاپ می‌شود (از روی فایل اکسل). خط به خط چک کنید.
غلطی دیدید؟ نام فایل را اصلاح کنید و دوباره همین دستور را بزنید. وقتی همه‌چیز درست بود، برو مرحله‌ی بعد.

### گام ۹ — تست دوم: یک پیام واقعی به «خودتان»

برای اینکه مطمئن شوید ارسال واقعی درست کار می‌کند، بدون ریسک، **به خودتان** یک پیام تست بفرستید:

1. فایل `مخاطبین.xlsx` را باز کنید؛ در ردیفِ **«ناحیه تست»**، در ستون‌های «نام در روبیکا» و «شماره»، نام و شماره‌ی **خودتان یا کسی که در روبیکا با او گفتگو دارید** را بنویسید؛ ذخیره کنید و ببندید. (اگر با خودتان گفتگو ندارید، از گوشی یک بار به مخاطبِ «مسئول نسرا ناحیه تست» پیام بدهید تا گفتگو ساخته شود.)
2. تصویر `کارنامه_ناحیه تست.png` باید در پوشه‌ی `کارنامه‌ها` باشد (که هست).
3. اجرا کنید (یا ساده‌تر: فایل `2-تست-به-خودم.bat`):

   ```
   python send_web.py --only "ناحیه تست" --limit 1
   ```

چه اتفاقی می‌افتد:
- پنجره‌ی مرورگر باز می‌شود و آدرس web.rubika.ir را می‌آورد.
- **بار اول فقط:** خودتان وارد شوید (انتخاب کشور و ایران، شماره همراه، بعدی، وارد کردن کدی که پیامک می‌شود).
- بعد از ورود، پیام را ببینید — اسکریپت خودش شروع می‌کند: جستجوی مخاطب، باز شدن گفتگو، ارسال تصویر با کپشن.
- چند دقیقه بعد در **روبیکای گوشی خودتان** چک کنید که تصویر و کپشن رسیده باشد ✅

> 💡 این لاگین فقط یک بار لازم است؛ دفعه‌های بعد مرورگر خودش وارد‌شده باز می‌شود.

### گام ۱۰ — ارسال کامل ۳۲ ناحیه

وقتی از تست راضی بودید:

1. تصویر و مخاطبِ «ناحیه تست» را حذف کنید.
2. مطمئن شوید dry-run (گام ۸) تمیز است.
3. اجرا:

```
python send_web.py
```

- ⏳ حدود **۲۵ تا ۴۰ دقیقه** طول می‌کشد (۹۶ پیام با فاصله‌ی امن برای جلوگیری از محدودیت روبیکا).
- مرورگر را **نبندید** و بگذارید کارش را بکند.
- در **تنظیمات Power ویندوز**، خوابیدن سیستم را موقتاً خاموش کنید (Control Panel → Power Options → Never).
- روند کار در همان پنجره‌ی سیاه، مخاطب به مخاطب نوشته می‌شود: ✅ موفق / ❌ ناموفق.

### گام ۱۱ — بعد از پایان

در پایان، گزارش جمع‌بندی چاپ می‌شود:

```
📊 نتیجه: ✅ 94 ارسال شد | ❌ 2 ناموفق | ↷ 0 رد شد
```

- اگر موردی ناموفق بود: معمولاً «مخاطب پیدا نشد» است. مشکلش را حل کنید و **همان دستور را دوباره اجرا کنید** — فقط موارد ناموفق دوباره ارسال می‌شوند، بقیه رد می‌شوند. (این ریزِ کارها در `sent_log.json` ثبت می‌شود.)
- اسکرین‌شات خطاها در پوشه‌ی `debug` هست.
- مرورگر را ببندید، تمام!

## بخش D — ماه‌های بعد (فقط ۵ دقیقه)

1. `month` را در `config.json` به ماه جدید تغییر دهید.
2. تصاویر جدید را در `کارنامه‌ها` بگذارید (اگر **نام فایل‌ها همانِ ماه قبل است**، فایل `sent_log.json` را حذف کنید تا دوباره ارسال شوند).
3. اگر مسئول ناحیه‌ای عوض شده، شماره‌اش را در `مخاطبین.xlsx` به‌روز کنید.
4. `3-لیست.bat` → چک → `4-ارسال.bat`

## 🆘 جدول رفع اشکال سریع

| مشکل | راه‌حل |
|---|---|
| `python is not recognized` | پایتون نصب نیست یا تیک PATH نخورده؛ گام ۱ را دوباره انجام دهید |
| `pip is not recognized` | به‌جای `pip` بنویسید: `python -m pip` |
| `playwright is not recognized` | بنویسید: `python -m playwright install chromium` |
| دانلود Chromium ناموفق | هیچ کاری لازم نیست؛ اسکریپت خودش از گوگل کروم/Edge استفاده می‌کند |
| «باکس جستجو پیدا نشد» یا «دکمه ارسال پیدا نشد» | `python send_web.py --inspect` را اجرا کنید؛ فایل‌های پوشه‌ی `debug` را برای سازنده بفرستید |
| «مخاطب پیدا نشد» | املای نام در دفترچه تلفن را با الگوی «نقش + نام ناحیه» تطبیق دهید؛ یا یک‌بار از اپ به او پیام بدهید |
| «شماره … پیدا نشد» | شماره را در `مخاطبین.xlsx` چک کنید: شاید اشتباه تایپ شده یا آن شخص روبیکا ندارد |
| «فایل مخاطبین.xlsx در اکسل باز است» | ذخیره کنید، ببندید و دوباره اجرا کنید |
| «openpyxl نصب نیست» | یک بار `1-نصب.bat` را اجرا کنید |
| «عنوان گفتگو نمی‌خواند» | نام نمایشی فرد در روبیکا با نام دفترچه فرق دارد؛ در config.json مقدار `verify_chat_title` را `false` کنید |
| وسط کار برق رفت / قطع شد | هیچ danych از دست نمی‌رود؛ فقط دوباره `python send_web.py` را اجرا کنید |
| متن فارسی در cmd به‌هم‌ریخته است | از Windows Terminal استفاده کنید یا در cmd دستور `chcp 65001` را بزنید |

## 🔜 بعداً: روش ۲ (ربات رسمی)

وقتی یک-دو ماه با روش ۱ کار کردید، پیشنهاد می‌کنیم روش ۲ را راه بیندازید که سریع‌تر و پایدارتر است (بدون مرورگر و بدون لاگین). راهنمای کاملش در `README.md` — بخش «روش ۲» است. خلاصه‌اش:

1. در rubika.ir/botapi یک ربات بسازید و توکنش را در `config.json` بگذارید.
2. `python send_bot.py --token TOKEN --listen` را باز نگه دارید؛ به مسئولان بگویید ربات را استارت بزنند و «ناحیه - سمت» خود را بفرستند.
3. از آن به بعد: `python send_bot.py --token TOKEN` — همین!

---

*سؤالی بود یا خطایی دیدید، خروجی پنجره‌ی cmd و فایل‌های پوشه‌ی `debug` را بفرستید تا دقیق راهنمایی کنم.*
