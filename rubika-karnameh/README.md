# 📨 ارسال خودکار کارنامه‌های عملکرد ماهانه در روبیکا

> 🚀 **تازه‌کار هستید؟ از [SETUP.md](SETUP.md) شروع کنید** — آموزش نصب و راه‌اندازی گام‌به‌گام از صفر (چند دقیقه‌ای خوانده می‌شود).

این مجموعه، تصاویر کارنامه‌ی هر ناحیه را به‌صورت خودکار برای **سه مسئول همان ناحیه**
(مسئول نسرا، فرمانده گردان، مسئول فضای مجازی) در روبیکا ارسال می‌کند.

فرض نام‌گذاری (قابل تغییر در `config.json`):

| فایل تصویر | نام ناحیه | مخاطبینی که جستجو و ارسال می‌شوند |
|---|---|---|
| `کارنامه_آران و بیدگل.png` | آران و بیدگل | `مسئول نسرا آران و بیدگل` ، `فرمانده گردان آران و بیدگل` ، `مسئول فضای مجازی آران و بیدگل` |

یعنی: هر تصویری که با «کارنامه_» شروع شود، بقیه‌ی نامش به‌عنوان «ناحیه» برداشته می‌شود
و به انتهای هر سه نقش چسبانده می‌شود تا نام مخاطبِ ذخیره‌شده در دفترچه تلفن ساخته شود.

---

## 🔀 دو روش — کدام را انتخاب کنم؟

| | روش ۱: نسخه وب (`send_web.py`) | روش ۲: ربات رسمی (`send_bot.py`) |
|---|---|---|
| شبیه چه کسی ارسال می‌کند؟ | اکانت شخصی خودتان (مثل ارسال دستی) | یک ربات روبیکا |
| راه‌اندازی اولیه | سریع — فقط لاگین در مرورگر | ساخت ربات + استارت‌زدنِ یک‌باره‌ی هر مسئول |
| پایداری | وابسته به ظاهر صفحه‌ی وب روبیکا (اگر روبیکا طرح سایت را عوض کند ممکن است نیاز به تنظیم مجدد داشته باشد) | بسیار پایدار (API رسمی روبیکا) |
| ریسک | با رعایت تأخیرها کم است، ولی ارسال انبوه از اکانت شخصی همیشه حساسیت دارد | تقریباً هیچ (راه رسمی خود روبیکا) |
| مناسب برای | شروع سریع همین ماه | استفاده‌ی هر ماهِه و بلندمدت |

**پیشنهاد:** همین ماه با روش ۱ کار را راه بیندازید؛ برای ماه‌های بعد روش ۲ را راه‌اندازی کنید.

## 🖥 روش ۱ — نسخه وب روبیکا (`send_web.py`)

### نصب (فقط بار اول)

پایتون ۳.۸ به بالا لازم است (سایت python.org — حین نصب تیک *Add to PATH* را بزنید). سپس در پوشه‌ی همین فایل‌ها:

```bat
pip install -U playwright
playwright install chromium
```

> 💡 اگر دانلود Chromium (حدود ۱۵۰ مگ) به هر دلیلی ناموفق بود، در `config.json` مقدار
> `"browser_channel"` را `"msedge"` بگذارید تا اسکریپت از **Edge خودِ ویندوز** استفاده کند
> — بدون هیچ دانلود اضافه‌ای. (`"chrome"` هم برای کروم کار می‌کند.)

### آماده‌سازی

1. تصاویر کارنامه را داخل پوشه‌ی `کارنامه‌ها` کنار اسکریپت بگذارید
   (یا در `config.json` مقدار `images_dir` را به مسیر واقعی پوشه‌تان تغییر دهید).
2. در `config.json` مقدار `month` را به ماهِ گزارش تغییر دهید (مثلاً «مهر ۱۴۰۵»).
3. مطمئن شوید این سه مخاطب **با همین نام‌ها** در دفترچه تلفن گوشی‌ای که اکانت روبیکایتان با آن است ذخیره شده‌اند و روبیکا آنها را نمایش می‌دهد (یک‌بار در اپ یا وب جستجویشان کنید).

### تست بدون ارسال (حتماً اول این را اجرا کنید)

```bat
python send_web.py --dry-run
```

فهرست ناحیه‌ها و گیرنده‌ها چاپ می‌شود؛ اگر جایی غلط بود، نام فایل یا `config.json` را اصلاح کنید.

### ارسال واقعی

```bat
python send_web.py
```

- مرورگر باز می‌شود؛ **بار اول** خودتان با شماره و کد تأیید وارد روبیکا می‌شوید (نشست ذخیره می‌شود و دفعه‌ی بعد دیگر لاگین نمی‌خواهد).
- بعد از ورود، اسکریپت خودش شروع می‌کند: هر مخاطب را جستجو می‌کند، گفتگو را باز می‌کند، تصویر را با کپشن می‌فرستد و بعدی.
- **تست کوچک اول:** `python send_web.py --only "آران و بیدگل" --limit 1` فقط یک پیام می‌فرستد تا مطمئن شوید همه‌چیز درست کار می‌کند.

### اگر وسط کار قطع شد؟

دغدغه نداشته باشید — ارسال‌های موفق در `sent_log.json` ثبت می‌شوند و با اجرای دوباره‌ی همان دستور، **فقط موارد باقی‌مانده** ارسال می‌شوند. برای ارسال مجدد همه از ابتدا: `--force`

### گزینه‌های کاربردی

| دستور | کار |
|---|---|
| `python send_web.py --dry-run` | فقط نمایش نگاشت، بدون ارسال |
| `python send_web.py --only "آران و بیدگل" "نجف‌آباد"` | فقط نواحی دلخواه |
| `python send_web.py --limit 3` | فقط ۳ پیام اول (تست) |
| `python send_web.py --month "مهر ۱۴۰۵"` | تغییر ماهِ کپشن بدون ویرایش فایل |
| `python send_web.py --force` | بی‌توجه به سابقه، همه دوباره |
| `python send_web.py --inspect` | حالت عیب‌یابی (پایین را ببینید) |

### عیب‌یابی روش ۱

- **«باکس جستجو پیدا نشد» یا «دکمه ارسال پیدا نشد»:** روبیکا ممکن است طراحی سایتش را عوض کند. `python send_web.py --inspect` را اجرا کنید؛ چند فایل در پوشه‌ی `debug` ساخته می‌شود (اسکرین‌شات + `dom_*.json`). این فایل‌ها را برای ما بفرستید تا سلکتورهای `config.json` دقیق شوند.
- **«مخاطب در نتیجه‌های جستجو پیدا نشد»:** یا نام ذخیره‌شده با نام مورد انتظار اسکریپت فرق دارد، یا آن مخاطب هنوز در لیست چت‌ها/مخاطبینِ وب دیده نمی‌شود. یک‌بار از اپ گوشی به او پیام بدهید تا در لیست بیاید، یا نامش را در دفترچه تلفن دقیقاً مثل الگو ذخیره کنید.
- **«عنوان گفتگوی بازشده نمی‌خواند»:** اگر نام نمایشی فرد در روبیکا با نام دفترچه تلفن فرق دارد این خطا می‌آید (برای ایمنی، ارسال نمی‌کند). در `config.json` مقدار `verify_chat_title` را `false` کنید.
- **فایل‌هایی که الگوی نامشان فرق دارد:** فایل `overrides.csv` بسازید (نمونه: `overrides.example.csv`) و در هر سطر، نام فایل و سپس نام/شماره مخاطبینش را بنویسید.
- **به‌هم‌ریختگی متن فارسی در ویندوز:** از Windows Terminal یا PowerShell استفاده کنید و اگر لازم شد `chcp 65001` بزنید.
- **کم کردن/زیاد کردن فاصله بین پیام‌ها:** مقادیر `min_delay_seconds` و `max_delay_seconds` در `config.json`. برای ۹۶ پیام، کل کار حدود ۲۵ تا ۴۰ دقیقه طول می‌کشد؛ مرورگر را نبندید و اجازه دهید سیستم روشن بماند.

## 🤖 روش ۲ — ربات رسمی روبیکا (`send_bot.py`)

### ۱) ساخت ربات

1. در روبیکا به آدرس **rubika.ir/botapi** بروید (یا از داخل اپ، پنل ربات‌ساز) و با اکانت خودتان وارد شوید.
2. یک ربات جدید بسازید و **توکن** آن را بردارید.
3. توکن را در `config.json` (کلید `bot_token`) یا هنگام اجرا با `--token` بدهید.

> توجه: طبق قوانین ربات‌های روبیکا، ربات فقط می‌تواند به کسی پیام بدهد که **یک بار ربات را استارت زده باشد.**

### ۲) ثبت یک‌باره‌ی مسئولان

```bat
python send_bot.py --token TOKEN --listen
```

این برنامه باز می‌ماند و گوش می‌دهد. به مسئولان (در گروه اعلامیه) این پیام را بفرستید:

> سلام؛ برای دریافت کارنامه‌ی عملکرد ماهانه از این پس به‌صورت خودکار، لطفاً ربات زیر را در روبیکا استارت بزنید و مطابق راهنما «نام ناحیه و سمت خود» را ارسال کنید.
> مثال: «آران و بیدگل - نسرا»

هر کس استارت بزند، ربات از او نام ناحیه و سمتش را می‌پرسد و در `bot_users.json` ثبت می‌شود. (روش دستی هم دارید: فایل `recipients.csv` — نمونه: `recipients.example.csv`.)

### ۳) بررسی و ارسال

```bat
python send_bot.py --token TOKEN --dry-run     ← چه کسی، چه چیزی دریافت می‌کند؟
python send_bot.py --token TOKEN               ← ارسال واقعی
python send_bot.py --token TOKEN --only "آران و بیدگل" --limit 1   ← تست تک‌پیام
```

محدودیت: تصاویر تا حدود ۱۰ مگابایت.

## ⚠️ نکته‌های مهم

- ارسال انبوه از اکانت شخصی (روش ۱) با تأخیرهای پیش‌فرض امن است، ولی مقادیر `min_delay_seconds`/`max_delay_seconds` را خیلی کم نکنید؛ روبیکا ممکن است اکانت را محدود کند.
- هر ماه قبل از ارسال، `month` را در `config.json` عوض کنید و اگر می‌خواهید سابقه‌ی ارسال ماه قبل پاک شود، `sent_log.json` را حذف کنید (در غیر این صورت فایل‌های هم‌نام دوباره ارسال نمی‌شوند).
- تصاویر و فایل‌های ثبت‌شده (شماره‌ها و مشخصات مسئولان) داده‌ی شخصی هستند و عمداً در گیت ذخیره نمی‌شوند (`.gitignore`).
